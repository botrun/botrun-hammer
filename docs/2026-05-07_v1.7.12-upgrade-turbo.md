# v1.7.12 升級指南 — 啟用本機 Whisper large-v3-turbo（0.5 秒轉錄）

日期：2026-05-07
版本：v1.7.12

## TL;DR

波特槌升級到 0.5 秒轉錄的版本，使用本機 `lightning-whisper-mlx` + `large-v3-turbo` 模型。

一鍵安裝/升級：

```bash
curl -fsSL https://raw.githubusercontent.com/botrun/botrun-hammer/main/install.sh | bash
```

或 clone 版本：

```bash
cd ~/coding_projects/botrun-hammer && git pull && ./install.sh
```

## 升級邊界 — 哪些自動，哪些 lazy install

### ✅ 會自動升級（install.sh / 每 4 小時自動檢查）

- `hammerspoon/botrun-hammer.lua`（主程式，VERSION 常數）
- `scripts/lwm_daemon.py`（本機 STT daemon，stdlib http.server，KISS 無 FastAPI）
- `scripts/lwm_daemon_ctl.sh`（daemon 啟停控制）
- 每 4 小時 Hammerspoon 會自動 fetch GitHub 最新版並跑 install.sh 同步上述檔案

### ⛔ 不會自動安裝（lazy install，KISS 原則）

- `lightning-whisper-mlx` Python 套件（約 1GB 依賴）
- `large-v3-turbo` 模型權重（首次推論時下載）

**為什麼故意不裝？** 避免只想用雲端引擎（Gemini/NCHC）的使用者被迫吞 1GB 依賴。
詳見 [v1.7.0 lightning-whisper-mlx daemon 設計](2026-05-06_lightning-whisper-mlx-daemon.md)。

## 啟用 turbo 的 4 步驟

1. **升級到 v1.7.12** — 等自動升級，或手動 `git pull && ./install.sh`
2. **切換引擎** — 點選單列波特槌圖示 → 引擎/模型 → 選「💻 本機 large-v3-turbo (繁中)」
3. **首次切換** — 自動執行 `pip install lightning-whisper-mlx` + 下載模型權重（一次性，需要等）
4. **之後開機** — v1.7.11 起，開機自動預載 daemon 進記憶體，按 fn+F5 即時可用

## 地雷經驗

- **不要手動 `pip install lightning-whisper-mlx`** — 讓 lua 選單觸發 lazy install，路徑與 Python 偵測都已處理
- **首次模型下載要等** — `large-v3-turbo` 約數百 MB，首次轉錄會卡，第二次起才是 0.5 秒
- **menubar 只露 turbo 一個本機選項**（v1.7.10 KISS 決策）— 避免使用者選擇焦慮，不要再加回 base/medium
- **install.sh 同時跑 cp 與 curl fallback** — 從 clone 跑會 cp 本地檔案；從 curl|bash 跑則 fetch GitHub raw，兩條路都要維持

## 驗證升級成功

```bash
# 1. 看版本（lua 第 29 行 VERSION 常數）
grep '^local VERSION' ~/.hammerspoon/botrun-hammer.lua

# 2. 看 daemon 腳本是否同步
ls -la ~/.hammerspoon/lwm_scripts/

# 3. 切到本機引擎後，看 daemon 是否上線
~/.hammerspoon/lwm_scripts/lwm_daemon_ctl.sh status
```
